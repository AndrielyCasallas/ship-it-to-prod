# Cloud computing: conceptos

## Modelos de servicio

```text
IaaS → infraestructura administrada por el equipo
PaaS → plataforma administrada por el proveedor
SaaS → aplicación consumida por usuarios
```

## Ideas esenciales

- **Elasticidad:** adaptar capacidad a la demanda.
- **Disponibilidad:** mantener el servicio accesible.
- **Región y zona:** distribuir riesgo físico y de red.
- **Coste:** medir consumo, capacidad reservada y operación.
- **Responsabilidad compartida:** el proveedor y el equipo protegen
  diferentes capas.

## Arquitectura

La nube no elimina la complejidad: cambia qué componentes se administran,
quién responde por ellos y cómo se mide su uso.
