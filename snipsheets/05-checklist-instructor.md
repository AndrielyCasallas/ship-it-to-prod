# Checklist conceptual

## Antes de publicar

- [ ] No hay credenciales, datos personales ni infraestructura privada.
- [ ] La configuración pública está separada de los secretos.
- [ ] Los artefactos generados están excluidos del repositorio.
- [ ] La documentación describe conceptos, no accesos internos.

## Antes de desplegar

- [ ] El cambio tiene validaciones automatizadas.
- [ ] Existe una estrategia de reversión.
- [ ] Los datos tienen una política de copia y recuperación.
- [ ] Hay señales para detectar errores y degradación.
