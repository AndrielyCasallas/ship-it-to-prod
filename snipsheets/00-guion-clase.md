# Mapa conceptual del proyecto

## Idea central

Una aplicación pasa por varias capas antes de llegar a producción:

```text
Código → Validación → Empaquetado → Despliegue → Observabilidad
```

## Conceptos clave

- **Producto:** frontend, backend, integraciones y datos.
- **Entrega:** automatización repetible desde el cambio hasta el despliegue.
- **Operación:** disponibilidad, seguridad, rendimiento y recuperación.
- **Evidencia:** tests, métricas, logs y revisiones.
